# Meta Business Manager Setup — Vaquero X Landscape
**Use this guide if client has ZERO existing Meta setup.**
Last updated: 2026-05-27

---

## BEFORE YOU START — What You Need From Him
- His personal Facebook account (email + password OR he logs in himself)
- His phone (for 2FA codes during setup)
- Business legal name, address, phone number, website URL

---

## STEP 1 — Create Meta Business Manager
1. Go to **business.facebook.com**
2. Click **Create Account**
3. Enter:
   - Business Name: `Vaquero X Landscape` (or his legal DBA)
   - Your name (his name as owner)
   - Business email (his preferred email)
4. Verify email when prompted
5. Fill out business details — address, phone, website

---

## STEP 2 — Create or Connect Facebook Page
**If he has NO Facebook Page:**
1. Inside Business Manager → left menu → **Accounts → Pages**
2. Click **Add → Create a New Page**
3. Page name: `Vaquero X Landscape`
4. Category: `Landscaping Company` or `Home Services`
5. Add profile photo + cover photo (use any job photo for now)
6. Click **Create Page**

**If he already has a personal Page:**
1. **Accounts → Pages → Add → Add a Page**
2. Enter the Page name or URL
3. Confirm ownership

---

## STEP 3 — Create Ad Account
1. Left menu → **Accounts → Ad Accounts**
2. Click **Add → Create a New Ad Account**
3. Name it: `Vaquero X Landscape - Ads`
4. Set currency: `USD`, Time zone: `Mountain Time (US & Canada)`
5. Click **Create Ad Account**
6. Add payment method:
   - His debit/credit card
   - Set **spending limit** if he wants a cap

---

## STEP 4 — Add CesarScales as Agency Partner
1. Left menu → **Settings → Business Settings**
2. Click **Partners → Add → Give a partner access to your assets**
3. Enter CesarScales Business Manager ID: *(add your BM ID here)*
4. Assign access to:
   - [x] His Facebook Page
   - [x] His Ad Account
5. Click **Send Request**
6. You accept from your Business Manager

---

## STEP 5 — Install Meta Pixel
1. Left menu → **Events Manager**
2. Click **Connect Data Sources → Web**
3. Name: `Vaquero X Pixel`
4. Enter website URL
5. Choose setup method:
   - **Manual install** (if no CMS) → copy the base code → paste before `</head>` on every page
   - **WordPress** → use the Meta Pixel plugin → paste Pixel ID
6. Click **Open Event Manager** → verify pixel is firing (green dot = live)

---
