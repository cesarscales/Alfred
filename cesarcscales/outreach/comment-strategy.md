# CesarScales — Comment Strategy
Goal: Get landscaping business owners to notice you, check your profile, and accept your DM.

---

## The Rule: Comments should add value or spark curiosity — never pitch in comments.

---

## Where to Comment

### Hashtags to Monitor Daily
- `#landscapingbusiness`
- `#lawncarebusiness`
- `#landscaper`
- `#lawnmaintenance`
- `#landscapinglife`
- `#smallbusinessowner`
- `#homeservices`

### What Posts to Target
- Before/after job photos
- "We're hiring" posts (growing business = needs more leads)
- "Busy season" posts
- Posts complaining about slow periods
- Posts showing off new equipment

---

## Comment Scripts

### On Before/After Photos
```
Clean work. Before/afters like this are exactly what converts 
when running ads — you sitting on a goldmine here.
```

```
That's a serious transformation. Work like this sells itself.
```

```
This is the kind of content that books clients. Looks great.
```

---

### On "Busy Season" Posts
```
Love to see it. Curious — are you running ads or is it mostly 
referrals keeping you busy?
```

```
Busy is good. The goal is making sure it stays that way 
year-round though 🤝
```

---

### On "Slow Period" or Complaint Posts
```
Slow periods are where paid ads make the biggest difference — 
you control the lead flow instead of waiting on referrals.
```

```
The businesses that push through slow season with ads come out 
ahead every time. Hang in there.
```

---

### On New Equipment Posts
```
New equipment deserves new clients to put it to work 👊
```

```
That setup is ready. Now you just need the leads to match it.
```

---

### General Engagement (builds familiarity before DM)
```
Hard work shows. 🔥
```

```
That's how you build a reputation.
```

```
Quality work right there.
```

---

## Comment → DM Flow

1. Comment on their post (genuine, adds value)
2. Wait 1–2 days
3. Send cold DM — they already recognize your name from the comment
4. Conversion rate is significantly higher than cold DM with zero prior contact

---

## Profile Must Look Legit Before You Comment
Before running this strategy make sure:
- [ ] Profile photo is set (logo or clean headshot)
- [ ] Bio clearly says what CesarScales does
- [ ] At least 3–6 posts on the feed (proof you're real)
- [ ] Website link in bio
